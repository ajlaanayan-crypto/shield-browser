6. Display Server Compositor Isolation Scope

ShieldBrowser's core privacy capability relies on communicating with the native macOS Quartz Display Server using CGWindowSharingType.none. This instructs the operating system compositor to exclude the window buffer from screen capture pipelines.

  • Intended Purposes: ShieldBrowser is engineered for private research, confidential documentation review, interview preparation, presentation note-taking, and sensitive web browsing during video conference calls.
  • No Physical Shielding: ShieldBrowser isolates its window from video capture streams only; it cannot shield your physical screen from physical room cameras, over-the-shoulder human onlookers, or enterprise hardware-level HDMI/DisplayPort capture capture cards installed externally.
