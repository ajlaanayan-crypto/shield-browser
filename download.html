macOS Security

First-Time Launch & Gatekeeper Assistance

Because ShieldBrowser communicates directly with low-level Apple Quartz Compositor APIs (CGWindowSharingType.none), macOS Gatekeeper may show a standard verification dialog upon first opening. Choose any of these 3 easy methods to launch:

Quickest 2-Click Method

  1. In Finder, navigate to your /Applications folder.
  2. Right-click (or Control-click) on ShieldBrowser.app and choose Open.
  3. When the confirmation popup appears, click Open. You will only need to do this once.

Via macOS System Settings

  1. Open System Settings from your Apple menu.
  2. Click Privacy & Security in the sidebar.
  3. Scroll down to the Security section.
  4. Click Open Anyway next to the ShieldBrowser notification.

Terminal One-Liner (Power Users)

Remove the quarantine attribute in one command:

xattr -cr /Applications/ShieldBrowser.app
